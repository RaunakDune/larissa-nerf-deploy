# Larissa-Synth v1

A small synthetic dataset for change detection on a spacecraft with 3D Gaussian
Splatting. It contains every image, label and camera used for the results in
`results/summary.json`, plus the trained baseline, so the detection results can
be reproduced without retraining (see `notebooks/larissa_walkthrough.ipynb`).

Generated by `tools/export_dataset.py` (seed 0), which replays the random
sequence of `run_demo.py`.

## Contents

| Folder | Files | Description |
|---|---|---|
| `train/` | 96 × (`rgb`, `depth`, `comp`) | Healthy satellite, cameras on a 9 m Fibonacci sphere; used to build the baseline |
| `holdout/` | 12 × `rgb` | Healthy satellite at held-out poses with pose error; used only for calibration |
| `inspection/<scenario>/` | 8 × (`rgb`, `gt`, `comp`) | Eight fixed inspection cameras (8.5 m, two rings at +28° and −12° elevation) |
| `dataset.json` | | Cameras for every image, component and material tables, noise settings |
| `baseline_gaussians.pt` | | Trained 3DGS baseline (43,929 Gaussians, component-labelled) |
| `baseline_meta.json` | | Baseline training time and settings |

Scenarios: `healthy_control`, `panel_hinge` (port array rotated 22° about its
hinge), `antenna_missing`, `mli_discoloration` (darkened blanket patch on the
bus +y face), `sun_shift_control` (Sun azimuth 98° instead of 68°).

## Formats

- `rgb_*.png`: 16-bit RGB PNG, linear intensity in [0, 1] scaled to 0..65535.
  Includes sensor noise (σ = 0.01) and exposure jitter (±3%). Load with
  `larissa.dataset.load_rgb16`.
- `depth_*.png`: 16-bit camera z-depth in millimetres, 0 for background.
- `comp_*.png`: 8-bit component id (0 background, 1 bus, 2 port solar array,
  3 starboard solar array, 4 antenna, 5 thruster).
- `gt_*.png`: 8-bit change mask, 255 where the component or material differs
  from the healthy satellite seen from the same true pose.
- Cameras: pinhole, `x_cam = R x_world + t`, camera looks along +z with y down.
  Inspection and held-out entries give both `camera_nominal` (the pose the
  system believes) and `camera_true` (the pose the image was rendered from;
  0.15° rotation and 1 cm translation error).

Resolution is 256 × 256 px throughout. Scene units are metres.

## Limitations

Rendered with a simple ray-caster (Lambert plus Blinn-Phong specular, hard
shadows, ambient term for Earth albedo, procedural textures). No motion blur,
lens effects, Earth background or real sensor model. Intended for method
development and demonstration, not for claims about performance on real
imagery.
